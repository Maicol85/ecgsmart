⚠️ Aviso Legal y Confidencialidad

Herramienta de apoyo clínico para la lectura y organización de electrocardiogramas. No reemplaza el juicio clínico del médico.

🔒 Los datos se procesan localmente y se envían únicamente a la API de Anthropic para el análisis de imagen.

⚕️ Las mediciones y el informe automático son orientativos. La interpretación final corresponde al médico tratante.

📋 Los desarrolladores no asumen responsabilidad por decisiones médicas basadas en este software.
🫀
ECGsmart
Electrocardiograma de 12 derivaciones · IA
Herramienta clínica que usa inteligencia artificial (Claude Vision) para leer, organizar y analizar electrocardiogramas de 12 derivaciones.
Cómo usar ECGsmart

API Key
